# 共同編集プラグイン

YMM4で、複数人が同じプロジェクトを同時に編集できるようにするプラグインです。

## 主な機能

- 部屋を作成して招待リンクを共有し、リアルタイムで共同編集
- 「通常の部屋」と、ホストがいなくても続けられる「常設ルーム」を選択
- アイテムの追加・移動・削除・プロパティ変更を相手に即時反映
- 相手の再生位置や、操作中のアイテムをタイムライン上に表示
- 画像・動画・音声・立ち絵などの素材ファイルを相手へ自動送信（大きいファイルは参加者どうしで直接送信）
- 相手の環境にないフォントやプラグインを使ったときに、双方へ通知
- YMM4 を持っていない人もブラウザから参加して編集
- ブラウザの参加者が書いた台本を、YMM4 側でボイスアイテムとして追加
- 通信が一時的に切れても、再接続したときに離れていた間の編集を取り戻す
- 参加者ごとの権限設定、キック、手動での「データを同期する」

## 使い方

1. ホストが部屋の種類を選び、「部屋を作成」を押します。
2. 表示された招待リンク、またはルームIDを相手に渡します。
3. 参加する側はリンクを開くか、ルームIDを入力して参加します。招待リンクからは、YMM4 で開くか、ブラウザでそのまま参加するかを選べます。

> [!Note]
 YMM4 で参加する人は、全員が **最新バージョンのプラグイン** を使っている必要があります。古いバージョンでは接続できません。

## 部屋の種類

| | 通常の部屋 | 常設ルーム |
|---|---|---|
| 使える期間 | ホストが部屋を閉じるまで | ホストがいなくても続けられる |
| 参加できる人数 | 最大100人 | 最大100人 |
| 内容の保存 | 参加者の YMM4 の中だけ | サーバーに保存され、最後に使われてから30日で削除 |

常設ルームは、アイテムが1つもないまま全員が抜けた場合はすぐに削除されます。

## ブラウザからの参加

招待リンクの「ブラウザで参加」から、YMM4 を持っていない人もパソコンやスマートフォンのブラウザで参加できます。

- タイムラインでのアイテムの追加・移動・削除、プロパティの編集ができます。
- プレビューは、部屋にいる YMM4 の参加者が描画して送ります。WebRTC が使える環境では H.264 の映像で、使えない環境では画像で表示されます。
- 素材は、必要になったものだけを YMM4 の参加者から受け取り、ブラウザの中に保存します。容量は「素材」タブで確認・削除できます。
- 音声の合成はブラウザでは行いません。「台本」タブで書いた台本は YMM4 の参加者の「台本」ページに届き、YMM4 側で「タイムラインに追加」するとボイスアイテムになります。

## 大きいファイルの直接送信

4MB以上のファイルは、中継サーバーを通さずに参加者どうしで直接送ります（設定の「ファイル」で変更できます）。

- 直接送る場合、相手にあなたのIPアドレスが伝わります。
- 直接つながらない場合は中継サーバー経由に切り替わります。ただし1GB以上のファイルは中継サーバーでは送りません。

## 素材の利用と二次配布について（重要）

このプラグインは、タイムラインで使われている素材ファイルを **ファイルそのものとして相手のPCへ送信** します。
これは素材の「再配布（二次配布）」にあたる場合があります。共同編集を始める前に、必ず以下を確認してください。

### 送信されるもの

| 種類 | 例 |
|---|---|
| 画像・動画・音声ファイル | 画像アイテム、動画アイテム、音声アイテムで読み込んだファイル |
| 立ち絵素材 | PSDファイル、動く立ち絵の画像一式（同じフォルダ内の画像もまとめて送信されます） |
| キャラクター設定で使っている素材 | キャラクターの既定の立ち絵など |

次のものは送信されません。

- **フォント**：相手のPCに同じフォントが入っていない場合は、警告が表示されるだけです。各自で正規に入手・インストールしてください。
- **音声合成エンジン**：セリフの音声は各参加者の YMM4 で生成されます。使うエンジンは各自が用意してください。

### 確認してほしいこと

1. **利用規約で再配布が禁止されていないか**
   多くの立ち絵素材、BGM・効果音、有料素材は「再配布禁止」とされています。
   共同編集の相手に送ることが再配布にあたるかどうかは、素材ごとの規約によって異なります。
   判断できない場合は、送信せずに **相手にも同じ素材を正規の配布元から入手してもらう** のが安全です。

2. **ライセンスが「利用者ごと」になっていないか**
   有料素材やフォントなどは、購入者本人しか使えないライセンスのことがあります。
   その場合、相手も自分でライセンスを取得する必要があります。

3. **クレジット表記などの条件**
   素材によっては、動画内や概要欄へのクレジット表記が利用条件になっています。
   共同編集で作った動画でも、使ったすべての素材の条件を満たしてください。

4. **自分が権利を持っていない素材**
   他人が作った画像・動画・音楽などを、許可なく送信・利用しないでください。

### 送信前の確認とファイルの扱い

- 素材を送信する前に、確認ダイアログが表示されます。送ってよいか分からない素材は **「いいえ」** を選んで送信しないでください。
- 送信できるファイルの種類は、設定の「ファイル」→「共有可能な拡張子」で制限できます。
- 送信・受信したファイルは「ファイル」タブで確認できます。
- 受信した素材は YMM4 の一時フォルダ（`MultiUserEdit\Media`）に保存されます。
  共同編集の目的以外で使ったり、さらに第三者へ渡したりしないでください。
  不要になった素材は「ファイル」タブから削除できます。
- ファイルは中継サーバー、または参加者どうしの直接通信で相手へ送られます。**中継サーバーはファイルを保存しません。**
- ブラウザの参加者が受け取った素材は、そのブラウザの中に保存されます。不要になったら「素材」タブから削除してください。
